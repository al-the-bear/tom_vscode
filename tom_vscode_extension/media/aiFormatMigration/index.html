Upgrade the workspace

This cannot be undone. The migration rewrites the _ai files of this workspace into the format of this Tom AI build. An older build cannot read them afterwards: everyone who shares this workspace — your other machines, and anyone syncing the same _ai — must upgrade Tom AI to this build too. Other windows of this machine on the workspace pause their runs and ask for a reload.
The _ai merge drivers — git merges the _ai files with them when a pull or reconcile brings two copies together (the migration itself uses the extension's own drivers and needs none).
