# `<app>_codespec_client`

Empty in this run, and legitimately so.

The client project holds screens, forms, semantic elements, actions, triggers,
navigation routes, view state and client configuration. All of them derive from
the experience-design and interaction-scenario parts of a specification, and
this sample's document writes neither: it is an information model and nothing
else.

The directory exists anyway. Phase 4 emits the trio whatever the specification
says (`codespecs_mapping.md` §4.2), so that the unit Phases 5 and 6 consume has
one shape rather than a shape that depends on its input.
